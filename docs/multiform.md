# Multiform

`Multiform` представляет варианты одной грамматической формы слова. В
[`lookup/table.py`](../lookup/table.py) это псевдоним типа `list[str]`:
каждый элемент — готовая строка с ударением, а список содержит все варианты,
полученные для одной ячейки парадигмы. Например, у существительного «болест»
есть два варианта творительного падежа единственного числа:

```python
from jezik.lookup import lookup

lookup("болест")["ins sg"].multiform
# ["бо̏лешћу", "бо̏лести"]
```

Грамматические признаки хранятся отдельно от списка: `LabeledMultiform` —
это пара `tuple[str, Multiform]`, например `("ins sg", ["бо̏лешћу", "бо̏лести"])`.
Метка состоит из разделённых пробелами обозначений признаков; конкретные
метки зависят от части речи и парадигмы. Наречие может иметь пустую метку.

## Как получить формы

`lookup()` возвращает `Multitable` — набор таблиц, поскольку запрос может
соответствовать нескольким словарным статьям или акцентным вариантам. Каждая
`Table` содержит последовательность пар «метка, Multiform». Отдельные формы
внутри одного списка отличаются от разных таблиц: последние представляют
разные найденные парадигмы или акцентные варианты.

```python
result = lookup("болест")
table = result[0]                  # таблица по индексу
cell = table["sg ins"]             # фильтр по грамматическим признакам
forms = cell.multiform             # список строк

for label, variants in table:      # все ячейки таблицы
    print(label, variants)
```

При поиске по строке порядок признаков не важен: `"ins sg"` и `"sg ins"`
совпадают. `Table` выбирает все ячейки, в метке которых присутствует каждый
переданный через пробел признак. Это поиск по целым признакам, а не по
подстроке или точному совпадению всей метки. Поэтому, например, `"sg"` может
вернуть несколько ячеек; пустой запрос соответствует всем ячейкам.
Результат фильтрации остаётся `Table`, даже если ничего не найдено.

Свойство `Table.multiform` доступно только тогда, когда в таблице ровно одна
ячейка. При нуле или более чем одной ячейке оно вызывает `AttributeError`.
Проверить число ячеек можно через `len(cell)`, а содержимое — итерацией.
Свойство возвращает сам хранящийся список, а не его копию; для независимого
изменения используйте `cell.multiform.copy()`.

Строковый индекс `Multitable` работает по-разному в зависимости от числа
таблиц:

- при одной таблице возвращает отфильтрованную `Table`, поэтому выражение
  `lookup(...)[...].multiform` может работать напрямую;
- при нескольких возвращает `Multitable` из непустых результатов фильтрации;
  выберите таблицу целочисленным индексом и убедитесь, что в ней одна ячейка;
- при отсутствии таблиц вызывает `ValueError`. Проверить результат поиска
  можно через `if result:` или `len(result)`.

Числовой индекс `Multitable` всегда выбирает таблицу по позиции. После
фильтрации нескольких таблиц результат остаётся `Multitable`, даже если в нём
оказалась только одна таблица.

## Откуда берутся варианты

Для поддерживаемой части речи `lazy_lookup()` создаёт объект `Noun`,
`Adjective`, `Verb` или `Adverb` и для каждого акцентного варианта строит
`Table` из генератора `word.multiforms(variant=i, yat=..., latin=...)`.
Генератор выдаёт пары «метка, список форм». При непосредственном вызове
`multiforms()` значение `variant=None` перебирает все акцентные варианты;
одинаковые метки при этом могут встречаться повторно, а не объединяться.

При построении ячейки парадигма перебирает допустимые варианты основ и
окончаний и применяет морфологические и акцентные правила. Словарные
`replacements` заменяют формы для соответствующей метки, а `amendments`
добавляют варианты к обычным формам. Затем внутренняя запись преобразуется
в отображаемую: в частности, учитываются `yat` и выбор латиницы. Повторяющиеся
итоговые строки удаляются с сохранением порядка первого появления. Пустой
список при этом остаётся возможным значением ячейки и отличается от
отсутствующей ячейки.

В публичном `lookup(word, input_yat="e", output_yat=None)` написание входного
слова определяет выбор латиницы; `output_yat`, если не задан, наследует
`input_yat`. Поддерживаются выходные режимы `e`, `je`, `ije`; входной `je`
нормализуется к `ije`. Подробнее об обозначениях словарных данных и внутренней
записи см. [NOTATION.md](NOTATION.md) и [YAML.md](YAML.md).

Основные реализации: [`lookup/table.py`](../lookup/table.py),
[`lookup/__init__.py`](../lookup/__init__.py), а также модули частей речи
[`noun`](../lookup/noun/__init__.py), [`adjective`](../lookup/adjective/__init__.py),
[`verb`](../lookup/verb/__init__.py) и [`adverb`](../lookup/adverb/__init__.py).
